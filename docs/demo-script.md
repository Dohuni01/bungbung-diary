# PT 시연 순서

5분 안에 핵심 기능을 다 보여주는 순서예요. Debug 패널 버튼으로 진행해요.

0. 앱을 처음 켜서 닉네임을 "킹카"로 정하고, 차 상태 불러오기를 보여준다. 심사위원 폰으로 QR을 찍어 가족 연결까지 보여주면 가장 좋다.
   - 할 말: "처음 만나는 순간부터 차가 자기 상태를 알려줘요. 이제 이 앱은 '킹카 일기'예요."
1. 오늘 일기를 띄우고 말투를 친구 → 집사 → 무뚝뚝으로 바꾼다. 음성도 들려준다.
   - 할 말: "데이터는 같고 말투만 달라요."
2. 타이어 공기압 경고를 띄우고, 정비소와 시간을 골라 예약 요청까지 간다.
   - 할 말: "경고가 예약까지 이어져요. 현대차 입장에선 정비 수요로 연결돼요."
3. 기어를 D로 바꾸고 엔진 경고등을 띄운다.
   - 할 말: "운전 중엔 글 없이 목소리로만 알려줘요."
4. 기어를 P로 돌리고 1만 km 돌파, 출고 1주년을 띄운다.
5. 주간 일기를 보내고 가족 공유 페이지를 보여준다.
6. 일기를 만든 요약 JSON과 프롬프트를 보여준다.
   - 할 말: "숫자는 데이터가, 말투는 AI가."

끝나면 "처음 상태로" 버튼으로 되돌린다.

## 시연 전 점검

- [ ] 네트워크를 끊어도 끝까지 진행되는지 (템플릿 + ON_DEVICE 음성)
- [ ] 에뮬레이터 Cold boot 후 첫 실행 시간
- [ ] 노트북 소리 출력과 발표장 스피커 연결
