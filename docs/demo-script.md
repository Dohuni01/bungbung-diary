# PT 시연 순서

5분 안에 핵심 기능을 다 보여주는 순서예요. 1번은 실제 첫 실행으로, 2번부터는 Debug 패널 버튼으로 진행해요.

1. 앱을 처음 켜서 부엉이를 고르고 닉네임을 "킹카"로 정한다. 심사위원 폰으로 QR을 찍어 가족 연결을 보여주고, 안 되면 "나중에"로 넘긴다. 설정이 끝나면 차 상태 불러오기와 첫인사를 보여준다.
   - 할 말: "처음 만나는 순간 차가 자기 상태부터 알려줘요. 이제 이 앱은 '킹카 일기'예요."
2. 오늘 일기를 띄우고, 설정에서 말투를 친구 → 집사 → 무뚝뚝으로 바꾼다. 음성도 들려준다.
   - 할 말: "데이터는 같고 말투만 달라요."
3. 타이어 공기압 경고를 띄우고, 정비소와 시간을 골라 예약 요청까지 간다.
   - 할 말: "경고가 예약까지 이어져요. 현대차 입장에선 정비 수요로 연결돼요."
4. 기어를 D로 바꾸고 연료 부족을 띄운다. "응"이라고 답해서 주유소를 경유지로 넣는다.
   - 할 말: "운전 중엔 글 없이 목소리로 묻고, 한마디로 답해요."
5. 기어를 P로 돌리고 1만 km 돌파, 출고 1주년을 띄운다.
6. 주간 일기를 보내고, 가족 폰의 카카오톡과 가족 공유 페이지를 보여준다.
7. 일기를 만든 요약 JSON과 프롬프트를 보여준다.
   - 할 말: "숫자는 데이터가, 말투는 AI가."

끝나면 "처음 상태로", 다시 처음부터 보여줄 땐 "첫 실행 세팅 다시 하기"를 누른다.

## 시연 전 점검

- [ ] 네트워크를 끊어도 끝까지 진행되는지 (템플릿 + ON_DEVICE 음성 + 가족 연결 "나중에")
- [ ] 에뮬레이터 Cold boot 후 첫 실행 시간
- [ ] 노트북 소리 출력과 발표장 스피커 연결
- [ ] 심사위원 폰으로 QR 연결할 때 쓸 서버 공개 주소
