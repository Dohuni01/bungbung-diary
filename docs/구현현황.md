## 1. 이번에 해결한 핵심 (가장 중요)

### 🔑 Pleos 권한 3단계 — "센서 전부 막힘"의 진짜 원인
- 증상: `registerTelltales / TirePressure / DoorPosition / SeatBelt / TurnSignal` 전부 `need Permission`.
- 원인: Pleos 권한을 **read 단계(`CAR_<X>`)만 선언**함. 실제로는 도메인마다 **3단계**가 있음:
  - `pleos.car.permission.CAR_<X>` (읽기)
  - `pleos.car.permission.CONTROL_CAR_<X>` (제어)
  - `pleos.car.permission.PRIVATE_CAR_<X>` (전용)
- 해결: `SAFETY / DOORS / LIGHTS / SEATS`의 **CONTROL_·PRIVATE_까지 선언** → `dumpsys`에서 모두 `granted=true` → **에뮬레이터에서 전 센서 실데이터 수신**.
- `pm grant`는 "not a changeable permission type"이라 불가 — **매니페스트 선언으로만** 부여됨(서명 권한 아님, install-time).
- 실차 서명빌드에서도 동일 권한으로 동작.

### 거리 측정
- `TRIP_CURRENT_DRIVING_DISTANCE` 계열은 에뮬레이터에서 값이 안 옴 → **`registerDistanceDriven`(PERF_ODOMETER)** 로 전환.
- 앱 시작 시점 오도미터를 baseline으로 잡고 **delta = 오늘 주행거리**.

## 2. 안전 알림 10종 — 구현 현황

위험도 3단계로 정리. **실데이터**(Virtual Console로 실제 재현) / **시나리오**(버튼으로 재현) 구분.

| 위험도 | 알림 | 실데이터 신호 | 에뮬 실데이터 | 버튼 재현 |
|:---:|---|---|:---:|:---:|
| 🔴 | 엔진 과열 | 텔테일 `ENGINE_TEMPERATURE` | ✅ | ✅ |
| 🔴 | 빨간 경고등 | 텔테일 `ENGINE_OIL_PRESSURE`/`MASTER_WARNING` | ✅ | ✅ |
| 🔴 | 타이어 공기압 급감 | 텔테일 `TPMS` | ✅ | ✅ |
| 🟡 | 주차브레이크 걸고 주행 | 텔테일 `PARKING_BRAKE` + 기어 D | ✅ | ✅ |
| 🟡 | 문·트렁크 덜 닫힘 | 텔테일 `DOOR_OPEN`/`TRUNK_OPEN` 또는 Door + 기어 D | ✅ | ✅ |
| 🟡 | 타이어 천천히 샘 | (며칠치 공기압 비교 — 미구현) | ❌ | ✅ |
| 🟢 | 졸음운전 | 텔테일 `DRIVER_ATTENTION` (※주행시간 누적 감지는 미구현) | 🔶 | ✅ |
| 🟢 | 블랙아이스 | 텔테일 `ICY_ROAD` (※온도+와이퍼 자체감지 미구현) | 🔶 | ✅ |
| 🟢 | 깜빡이 계속 켜짐 | `TurnSignal` 상태 | ✅ | ✅ |
| 🟢 | 비 오는데 창문 열림 | `Wiper` ON + `Window` Open | ✅ | ✅ |

> 추가로 안전벨트: `Telltales → Seat Belt` 텔테일 ON = "안 맴"(실차 경고등과 동일 의미). 실데이터 동작 확인.

### 동작 방식
- **수동(DebugPanel 버튼)** 우선 → 없으면 **실데이터 자동 감지**(`AppState.autoSafetyAlert`).
- 수동 버튼은 멘트 + 관련 상태(주행시간·타이어·온도)도 같이 세팅해 "실제처럼" 보이게 함.
- 안전 멘트는 **말투 무관·농담 없이 1~2문장 고정** (위급 시 안전 우선 원칙).
- 🔴/일부 🟡 알림은 "주행 중" 큰 화면 + 정비소 버튼.

## 3. Virtual Console 실데이터 재현 방법 (발표용)

| 보여줄 알림 | Virtual Console 조작 |
|---|---|
| 엔진 과열 | Safety → Telltales → **Engine Temperature** ON |
| 빨간 경고등 | Safety → Telltales → **Engine Oil Pressure / Master Warning** ON |
| 타이어 급감 | Safety → Telltales → **TPMS** ON |
| 주차브레이크 주행 | Telltales → **Parking Brake** ON + Gear **D** |
| 문 덜 닫힘 | Telltales → **Door Open** ON (또는 Door Position Open) + Gear D |
| 블랙아이스 | Safety → Telltales → **Icy Road** ON |
| 졸음운전 | Safety → Telltales → **Driver Attention** ON |
| 안전벨트 | Telltales → **Seat Belt** ON (= 안 맴) |
| 비 + 창문 | **Wiper** ON + **Window** Open |
| 깜빡이 | **Turn Signal** L/R |

> Virtual Console에 없는 항목이나 백업은 DebugPanel의 버튼 사용.
